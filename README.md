# Handled Documentation

Official documentation for the Handled integration infrastructure platform.

## Overview

This repository contains the documentation for Handled, an integration infrastructure platform for commerce. Connect to 150+ ecommerce, WMS, carrier, and logistics services through a single unified API.

## Development

Install the [Mintlify CLI](https://www.npmjs.com/package/mint) to preview documentation changes locally:

```bash
npm i -g mint
```

Run the development server:

```bash
mint dev
```

View your local preview at `http://localhost:3000`.

## Structure

- `/how-handled-works` - Platform overview and concepts
- `/integrations` - Integration management documentation
- `/unified-apis` - Unified API documentation
- `/integrated-accounts` - Account connection documentation
- `/webhooks` - Webhook configuration and events
- `/link-sdk` - Embedded connection UI documentation
- `/rapid-bridge` - Sync job documentation
- `/rapid-form` - Form configuration documentation
- `/workflows` - Workflow automation documentation
- `/platform` - Environments, team members, and API tokens
- `/api-reference` - Complete API reference
- `/unified-realtime` - Unified Realtime API reference
- `/unified-cache` - Unified Cache API reference

## Publishing

Changes pushed to the main branch are automatically deployed to production.
