---
title: "Unified Commerce Cached API"
---

**How it works:** We continuously sync data from your connected commerce platforms into our database. When you make an API request, you query our stored data in a unified format.

**Best for:**

- Read-heavy workloads (e.g., product catalogs, order history)
- Analytics and reporting
- Building fast UIs where millisecond latency matters
- Powering automations on the Handled platform—synced data can trigger workflows like order routing, inventory allocation, fulfillment assignment, and more

**Automation examples:**

- **Order routing:** Automatically route synced orders to the optimal warehouse or 3PL based on inventory levels, shipping zones, or cost rules
- **Inventory synchronization:** Push updated stock levels to all connected sales channels when inventory changes
- **Low stock alerts:** Trigger purchase order creation or notifications when inventory drops below thresholds
- **Fulfillment orchestration:** Split orders across multiple fulfillment locations based on item availability
- **Customer segmentation:** Tag and categorize customers based on order history for targeted workflows
- **Invoice generation:** Auto-generate invoices in your ERP when orders reach "shipped" status

**Tradeoffs:**

- Data freshness depends on sync frequency
- Write operations still go through Realtime
- Requires initial sync before data is available
