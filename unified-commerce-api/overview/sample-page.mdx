---
title: "Unified Commerce Realtime API"
---

**How it works:** We proxy your API requests directly to the underlying platform in real-time, translating between our unified format and the platform's native API.

**Best for:**

- Write operations (creating orders, updating inventory)
- Use cases requiring guaranteed fresh data
- Transactional workflows where you need immediate confirmation
- Developers building apps that pull data from multiple commerce platforms but need it in a single, unified format
- Passthrough API calls—access the underlying platform's native API directly through Handled when you need platform-specific functionality not covered by our unified model

**Tradeoffs:**

- Higher latency (depends on the underlying platform's response time)
- Rate limits inherited from connected platforms
- More complex error handling (network failures, API limits, etc.)
- Data is not persisted in Handled—cannot be used to trigger automations on the Handled platform
